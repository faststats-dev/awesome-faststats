# Contribution Guidelines

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.

## Adding an entry

Ensure your pull request adheres to the following guidelines:

- Make an individual pull request for each suggestion.
- Use the title format `Add Name of Project`.
- Search previous suggestions before making a new one, to avoid duplicates.
- Only submit SDKs and projects that actually work with FastStats and are actively maintained.
- Add your entry to the right section: **SDKs** (under its language) or **Built with FastStats**. If a language section doesn't exist yet, add it in alphabetical order.
- Add new entries to the bottom of their section.
- Use the following format:

  `- [Name](link) - Description.`

- Link to the GitHub repo or the project's homepage, not a blog post about it.
- Keep descriptions short and simple, but descriptive.
- Start the description with a capital letter and end it with a period.
- Don't start the description with "A" or "An", and don't repeat the name of the project.
- For **Built with FastStats** entries, say what the project is and, optionally, how it uses FastStats.
- Don't use marketing language like "the best" or "blazing fast".
- Check your spelling and grammar.
- Make sure your text editor removes trailing whitespace.
- Don't open a draft or WIP pull request. It should be ready to merge when you open it.

## How to contribute

1. Go to the [README](README.md) on GitHub.
2. Click the edit (pencil) icon. GitHub will fork the repo for you.
3. Add your entry, following the guidelines above.
4. Click **Propose changes**, then **Create pull request**.
5. Say why you're proposing the change in the pull request description.

Sometimes a maintainer will ask you to edit your pull request before it's merged. This is usually because of spelling errors or because the entry doesn't match the guidelines.

## Updating your pull request

To update a pull request you've already opened, push new commits to the same branch. There's no need to open a new one.

Thank you for your suggestions!

## Show it off

Once your entry is merged, feel free to add this badge to your project's README:

```markdown
[![Mentioned in Awesome FastStats](https://awesome.re/mentioned-badge.svg)](https://github.com/faststats-dev/awesome-faststats)
```

Please use the badge as is, without modifying it.

Thank you for your suggestions!
